остаётся исследованием: дрейф лиц/фактуры и изменение кадрирования не приняты для UI.
Не требуется запускать новый платный рендер при каждом изменении макета.

Оба PNG вместе — 2,63 MB. Это исходники для локального прототипа, не оптимизированная
доставка для production. Перед выпуском нужны варианты под реальный размер экрана,
проверка качества и согласование окончательного иллюстративного стиля.
