# Красная панда в прототипе

27 сентября 2026. По запросу пользователя выбранная красная панда с тёмно-коричневой
повязкой интегрирована без анимаций.

## Где смотреть

В прототипе выберите «Клиент» → «Первый вход» в настольном списке экранов:
«Активна» — приветствие, «Принята» — большой палец, «Нет занятия» — сидящая панда.
В сценарии «Пусто»: «Программа» — панда с планшетом, «Прогресс» — нейтральная стойка.
Ошибка приглашения по-прежнему использует значок ссылки.

## Ассет и отображение

`assets/mascot/red-panda-dark-headband.png` — побайтовая копия выбранного мастер-листа
`design-exploration/mascot-sheets-2026-09-26/red-panda-dark-headband.png`.
SHA-256: `27015be9a64fdcf049bbcbad39c1bf7e1b43c9a87c1a39391c5b99f952993ec5`.
Персонаж не перерисовывался и не генерировался заново. `js/mascot.js` выбирает пять
поз координатами CSS-кадрирования. Старый движок покадровых реакций удалён из рабочего
компонента, вызов `Mascot.sync` убран из рендера приложения.

Мастер имеет бумажный фон, не alpha. CSS brightness(1.08) и multiply скрывают светлую
бумагу на текущем светлом canvas; цвета самого персонажа также немного светлеют.
Это решение для текущего прототипа: для тёмной темы/других поверхностей нужны отдельные
прозрачные ассеты. Координаты привязаны к мастер-листу 1536×1024; не заменять файл
другим листом без пересмотра кадров. Маска позы ожидания исключает руку соседней позы.

Размер области 216×216 в первом входе, 162×162 в пустых состояниях, 120×120 на коротких
экранах. Изображение декоративное (alt="", aria-hidden), не перехватывает ввод.
Исторические листы, ассеты и review-страницы рыси сохранены.

## Проверка

10/10 целевых Playwright-проверок: desktop и ширины 320/375/390/430, пять поз,
загрузка мастер-листа, отсутствие анимации и переполнения, кнопка на 320×640,
переход из приглашения на главную. Снимки: `output/red-panda/results/`.
TypeScript e2e-проверка пройдена. Физический iPhone/Safari не проверен.
