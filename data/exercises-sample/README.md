# Демонстрационная выборка упражнений

12 упражнений из https://github.com/hasaneyldrm/exercises-dataset (ветка main, скачано 28 сентября 2026).

Откройте `index.html` в браузере: страница работает локально без сервера, показывает GIF, русские инструкции и поиск по русскому/английскому названию.

- `exercises.json` — исходные записи выбранных упражнений; добавлены `name_ru` и `aliases` для нашего проекта.
- `exercises.js` — те же записи для локального просмотра без fetch.
- `images/` — миниатюры 180×180.
- `videos/` — GIF 180×180 (это анимации, не видеофайлы).
- `LICENSE` и `NOTICE.md` — исходные уведомления поставщика.

Данные и инструкции поставляются под MIT. Медиа принадлежат Gym visual и не покрываются MIT. Пользователь планирует согласовать лицензию с Gym visual; лицензия для этого проекта пока не получена. Сохранены исходные attribution и разрешение файлов. Перед публикацией приложения необходимо завершить согласование медиа.

Русские названия добавлены вручную. Русские инструкции взяты из набора без редакторской или тренерской проверки. Выборка подключена к рабочей библиотеке `prototype-fresh`: 11 записей обогащают существующие упражнения, одна добавляет отдельный вариант тяги верхнего блока. Локальные медиа и исходные лицензии скопированы в `prototype-fresh/assets/exercises/`.
