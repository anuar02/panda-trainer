# SOM-22/23 — библиотека и редактор на реальных данных

Дата: 01.10.2026. [ADR 0035](../../../docs/app/decisions/0035-authenticated-library-editor.md).

## Реализация

- `/workspace/library`, `/workspace/library/editor`, `/workspace/library/template/[id]`:
  отдельные авторизованные маршруты с общими компонентами прототипа.
- UUID сохраняется во всех операциях; `source_key` связывает упражнение только
  с упакованными изображениями. Демо e0…e80 не отправляются в RPC.
- Активный поиск, создание своего упражнения из поискового запроса, архивирование
  с подтверждением; сохранённый шаблон разрешает UUID архивного упражнения.
- Сохранение, редактирование и копия через атомарный RPC с expected revision.
  Черновик и pending command разделены по пользователю/workspace; request UUID
  сохраняется до отправки и восстанавливается после рестарта.
- Сессия закреплена за исходным пользователем на конкретном RPC. Смена аккаунта
  перед отправкой отклоняет старую команду, секреты не сохраняются в черновике.
- Пагинация чтения не обрезает составы шаблонов при лимите PostgREST. После
  архивирования упражнение скрывается из выбора, но не из старых шаблонов.

## Проверки

- `npm run check`: 398 тестов / 55 suites, TypeScript, ESLint, Prettier проходят.
- `npm run export`: iOS, Android, web проходят.
- 11 transport/adapter tests: UUID/media mapping, архивные ссылки, вес/заметки,
  повтор immutable payload, восстановленный request ID, чужая сессия и 1 200
  строк шаблонов через несколько страниц.
- 6 provider tests: изоляция/восстановление черновика, revision, ответ сервера
  при ошибке очистки, pending save после рестарта, повреждённое хранилище и
  размонтирование во время записи до запроса.
- Общие UI regression tests сохраняют демо и проверяют переданные реальные
  упражнения, время, media, архивную ссылку и отсутствие ложного действия.
- 11 headless browser checks проходят: каталог, своё упражнение, сохранение и
  reload шаблона, редактирование/копия, архивирование и переход по карточке
  шаблона с сохранённой архивной ссылкой. Синтетические данные удалены.

Воспроизводимый headless сценарий с изолированными Supabase/Auth/Mailpit:

```sh
node app/review/workspace-library/verify.cjs \
  --workdir /path/to/isolated/supabase-workdir \
  --container supabase_db_trainerApp-som18 \
  --origin http://localhost:8088
```

Снимки 390×844 находятся локально в `/tmp/screens/workspace-library/`.
Проверен реальный дефект фона вложенного Stack: он теперь использует canvas темы,
поэтому белые заголовки тренерского интерфейса не исчезают на белом фоне.

## Открыто

Назначение личной программы — следующий пакет SOM-24, создание занятия — SOM-26.
Кнопка создания занятия в реальном template detail пока отключена. Избранное
пока живёт только в состоянии экрана. Browser coverage не заменяет native,
сверку всех тем/состояний и owner acceptance. Новые точки создания и архива
требуют этой приёмки; экраны не объявлены завершёнными.
