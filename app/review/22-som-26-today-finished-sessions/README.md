# SOM-26 · Завершённые занятия на «Сегодня»

05.10.2026, бриф 22. База `336090c` включает спокойный Today (#88),
сохранённый после удаления снимков (#90), и последующие исправления NativeTabs.
Экран и SOM-26/SOM-45 не приняты: одобрение владельца остаётся открытым.

## Что изменилось

В эталоне, демо и серверном представлении завершённый журнал относит занятие
к «Прошло» независимо от запланированного окончания. Фокус выбирается среди
незавершённых; завершённое занятие не дублируется в «Сейчас»/«Следующее» и ленте.
Сообщение «Все занятия на сегодня позади» возможно только без фокуса и ленты.
Метка «до …» берёт конец последней показанной неотменённой строки ленты.
Для пересекающихся интервалов это конец последней строки, а не максимум дня.

Серверные завершения читаются из `workout_instances.finished_at` для booking IDs
текущего дня с фильтром workspace, runtime-проверкой строк и проверкой
авторизованной сессии до и после запросов. Чтение пакетное, с ограниченной
пагинацией. Для мини-группы учитываются все неотменённые участники:
группа завершена, когда завершены их журналы. Correction draft не отменяет
сохранённый `finished_at`. Демо-состояние не определяет production-завершение.

Hook обновляет статусы при изменении контекста журнала/sync state, возврате
приложения на передний план и раз в минуту. Поздние ответы после смены
аккаунта, workspace или поколения сессии отбрасываются. При ошибке сохраняются
последние статусы того же scope, показываются сообщение и повтор загрузки.
Изменения расписания/журналов на сервере не выполняются.

После удаления завершённых строк пересчитываются интервалы ленты:
их прежние свободные окна и пересечения не создают пустой «Дальше».
Флаг «Журнал завершён» остаётся в раскрытых прошедших занятиях.
Правило владельца сохранено в [ADR 0115](../../../docs/app/decisions/0115-finished-journals-are-past-on-today.md).

журнала Store.logging: в 20:30 завершены s6 «Мини-группа» и s7 «Айгерим» —
нет фокуса/ленты/метки, есть «позади» и «Прошло 7 занятий»; частичное завершение
переводит s7 в «Следующее». Проверены пересечения, отсутствие ложных маркеров
и конец последней строки вместо максимума дня.

Финальная фокусная проверка: **7 suites / 73 tests прошли**, 6.726 s.
Reader/hook внутри неё: **11/11 тестов прошли**. Проверены workspace/booking фильтры,
невалидные и чужие строки, отказ запроса, смена аккаунта, выход во время
чтения и восстановление после ошибки с сохранением scoped-данных.

Полная проверка приложения: **зелёная**, TypeScript strict, ESLint без warnings,
Prettier и **3362/3362 теста в 261 suite**. Итоговый повтор `npm run check`
после всех правок: 261 suite, 3362 tests, 42.093 s (Jest).
`git diff --check` — без ошибок. В существующих native marker/других экранных
тестах остаются предупреждения React о duplicate child keys; тесты проходят.
