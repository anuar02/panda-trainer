# Приложение

Действуют `../AGENTS.md` и `../docs/app/CONVENTIONS.md`.
Маршруты находятся в `app/`, остальной код — в `src/` по архитектуре репозитория.
Перед изменениями Expo сверять API с документацией установленного SDK.
Зависимости добавлять через `npx expo install`; проверка — `npm run check`.
