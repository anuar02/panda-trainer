# Библиотека и конструктор шаблонов

Библиотека доступна в нижней навигации тренера. Разделы: упражнения и шаблоны.

## Сценарии

- Поиск по русскому и английскому названию, синонимам, группе мышц и оборудованию.
- Совместные фильтры: группа мышц, оборудование, избранное, наличие демонстрации техники.
- Карточка упражнения: локальный GIF и инструкция, когда они доступны.
- Шаблоны: просмотр состава, создание, редактирование и копирование.
- Конструктор: множественный выбор упражнений, порядок, удаление из плана, подходы, повторения/диапазон или секунды, вес и отдых.
- Черновик автоматически сохраняется; его можно продолжить после перезагрузки либо удалить с подтверждением.
- Сохранённый шаблон можно выбрать при создании занятия. Кнопка в карточке шаблона заранее выбирает план в форме занятия.

## Данные

`js/template-repository.js` загружается после `data.js`, до восстановления сессий. Шаблоны, черновик и избранное хранятся в localStorage с ключами `trainer-prototype:templates:v1`, `trainer-prototype:template-draft:v1` и `trainer-prototype:exercise-favorites:v1`. Это локальное хранение прототипа, без синхронизации между устройствами.

Редактор не меняет исходные данные до успешной записи в хранилище. При переименовании прежний ключ программы и её снимок остаются доступны ранее назначенным занятиям. Уже открытые журналы используют собственные снимки плана. Ошибка хранилища показывается пользователю; успешное сохранение не имитируется.

## Интерфейс

Используются действующие токены палитры и шрифты приложения. Основные элементы: поиск, компактные карточки движений, номер упражнения в плане и нижняя кнопка сохранения. Отступы кратны 4 px; карточки упражнений — 16 px радиус, шаблоны — 20 px. Доступны состояния пустого поиска, пустого избранного, пустого плана, ошибки формы и ошибки хранилища. Выбор упражнений использует существующий модальный лист с удержанием фокуса.

## Проверка

```sh
node --test prototype-fresh/tests/*.test.cjs
python3 -m http.server 8788 --bind 127.0.0.1
```

Во втором терминале:

```sh
node prototype-fresh/tests/library.browser.cjs
```

Для другого сервера задайте `LIBRARY_TEST_URL`. Браузерная проверка использует изолированный контекст, не затрагивает пользовательское хранилище, проверяет основные сценарии и сохраняет снимки в `output/library-review/`.

Ориентиры: мобильное устройство/4G, интерфейс кабинета без SEO, WCAG AA (проверка — Codex в рамках этой задачи). Цели для будущего измерения p75: LCP ≤ 2500 мс, INP ≤ 200 мс, CLS ≤ 0,1. Бюджет: до 200 KB gzip начального JS и до 80 KB на новый раздел; библиотека с хранилищем добавляет около 10 KB gzip, весь начальный JS — около 118 KB gzip. Цели Lighthouse: accessibility ≥ 90, performance ≥ 90. Lighthouse и полевые p75-метрики в этой проверке не измерялись.
