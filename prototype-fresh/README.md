## Что изменилось

**Маскот.** 19 прозрачных спрайтов в `assets/mascot/`: 10 поз (`front`, `wave`, `thumbs`,
`jump`, `sit`, `clipboard`, `stretch`, `sleep`, `side`, `three-quarter`) и 8 лиц (`face-*`).
Все вырезаны из утверждённого мастер-листа
`design-exploration/mascot-sheets-2026-09-26/red-panda-dark-headband.png`: фон удалён
заливкой от краёв, края сглажены без светлой каймы. Персонаж не перерисовывался.
Прежние кадры по CSS-координатам и `mix-blend-mode: multiply` больше не нужны.

Где появляется панда:

- «Сегодня» у тренера: приветствие по времени суток и тёмная карточка-сводка. В ней
  лицо панды меняет эмоцию, есть прогресс дня и кнопка входящих запросов.
- Главная клиента: машущая панда в hero-карточке, с планшетом, если нужен ответ.
- Приглашение, пустые состояния (спит / сидит), журнал без выбранного занятия.
- Тосты: смеётся при успехе, волнуется при предупреждении.
- Празднование с конфетти и прыгающей пандой после подключения, завершения тренировки,
  подтверждений, оплаты и записи посещения.
- Логотип в боковом меню и favicon.

**Анимации** (`css/fresh.css`, `js/fx.js`):

- Появление экрана с каскадом блоков. Запускается только при смене экрана, роли
  или сценария, а не при каждом перерисовывании.
- Для каждой позы свой цикл: покачивание, дыхание, взмах, кивок, прыжок, сон с «z».
  Тень под пандой синхронизирована с циклом. По клику панда подпрыгивает.
- Пружинные нажатия кнопок, блик на основной кнопке, парящий таб-бар
  с «пузырём» активного пункта, рост прогресс-баров, мерцающие скелетоны,
  пружинный выезд листов и тостов.
- `prefers-reduced-motion`: все движения и эффекты отключаются.

**Палитра** взята из персонажа: кремовый фон, шоколадный текст и тёмные карточки,
ржаво-оранжевый акцент. Проверено по WCAG AA: белый на кнопке 4,96:1, акцент на белом 5,02:1,
вторичный текст на фоне 5,95:1, активная вкладка 5,5:1.

## Голосовой ввод в журнале тренировки

Кнопка «Голос» рядом с «Завершить тренировку» работает как рация: **удерживайте и говорите**.
Пока кнопка зажата, из-за неё выглядывает панда с планшетом. Она наклоняет голову и
«слушает», в облачке — живой текст и уже понятые записи. Отпустили — панда «разбирает»,
показывает «Понял: 3 записи» с большим пальцем, и открывается компактный лист
«Проверьте запись». Если ничего не слышно или нет доступа к микрофону, панда пожимает плечами
и объясняет, что случилось. Короткое нажатие открывает полный лист с текстовым полем и
демо-фразами. С клавиатуры — удерживать пробел или Enter, Escape отменяет.

Тренер говорит обычными фразами:

| Фраза | Что получится |
| --- | --- |
| «Приседания 80 на 8» | следующий пустой подход приседаний: 80 кг × 8 |
| «80 на 10» | следующий пустой подход текущего упражнения |
| «Ещё один такой же» | копия предыдущего подхода |
| «Отжимания 15 раз», «планка 45 секунд» | упражнения без веса |
| «Тяга второй подход 35 на 10» | конкретный подход, с пометкой «заменит записанный» |
| «Арман, жим 45 на 8» | в мини-группе — подход другому участнику |
| «Заметка: колено уходит внутрь» | заметка тренера к занятию |

Числа словами («восемьдесят два с половиной») распознаются. Распознанное показывается
карточками; в журнал ничего не пишется, пока тренер не нажмёт «Записать», любую
карточку можно убрать. Неизвестное упражнение, заполненное упражнение или непонятная
фраза показываются как ошибка и не записываются.

Распознавание — Web Speech API браузера (`ru-RU`). Где его нет или микрофон запрещён,
работает текстовое поле. Демо-фразы «надиктовываются» с анимацией, поэтому сценарий
можно показать на любом устройстве. В Chrome звук обрабатывается на серверах Google —
это сказано в листе. Заметки хранятся в журнале занятия (`notes`) рядом с подходами.

## Гибкий журнал: план и факт

Программа — план, журнал — факт. На тренировке тренер меняет факт как угодно,
программа клиента при этом **не меняется**.

| Действие | Где | Как видно |
| --- | --- | --- |
| Лишний подход | «+ Подход» под упражнением, меню «⋯» | «сверх плана» у подхода |
| Убрать пустой лишний подход | «− Убрать пустой» | — |
| Заменить упражнение | меню «⋯» → «Заменить» | «↔ вместо …»; записанные подходы остаются у старого |
| Пропустить | меню «⋯» → «Пропустить», можно «Вернуть» | зачёркнуто, «пропущено» |
| Добавить упражнение | «+ Добавить упражнение» | «+ не из программы» |
| Тренировка без программы | журнал стартует пустым | «Добавить упражнение» |

Выбор упражнения — поиск по библиотеке (`DB.exerciseLibrary`, 23 упражнения). Своё упражнение
создать можно, но кнопка стоит под найденными и становится тише, если похожие есть:
так меньше дублей вроде «Бицепс» и «Сгибания на бицепс». Изменения — только для текущего
участника мини-группы.

Голос понимает то же самое: «вместо тяги делаем жим гантелей», «пропускаем планку»,
«бицепс 12 на 12» (найдёт «Сгибания на бицепс с гантелями» или предложит своё),
«приседания 60 на 8», когда все подходы уже записаны (станет подходом сверх плана).
«Ещё такой же» и «80 на 10» без названия относятся к последнему названному упражнению.
Всё по-прежнему подтверждается кнопкой «Записать».

При завершении и в результатах — сводка «Отличия от программы: заменено 1 · добавлено 2 ·
пропущено 1». Обновить программу по итогам тренировки — следующий шаг: программы в данных
общие для нескольких клиентов, и правка требует отдельного решения.

Модель данных: у упражнений журнала появились `origin` (`added` / `replaced`), `replaces`,
`skipped`, `replacedBy`, `plannedSets`, `unit`. Старые журналы читаются без миграции.

## Файлы

| Файл | Роль |
| --- | --- |
| `css/fresh.css` | токены и переопределения поверх исходных стилей, все анимации |
| `js/mascot.js` | `Mascot.render(pose, context)` и `Mascot.face(mood, size)` |
| `js/fx.js` | празднование, искры при записи подхода, реакция на клик |
| `js/voice.js` | `VoiceParse` (разбор фраз) и `Voice` (распознавание, лист, запись) |
| `js/flex.js` | поиск по библиотеке, выбор и создание упражнения |
| `js/app.js` | флаги `is-entering` / `is-fresh` и вызов `Fx.afterAction` |
| `js/screens/*.js`, `js/ui.js` | места появления панды, сводка дня |
