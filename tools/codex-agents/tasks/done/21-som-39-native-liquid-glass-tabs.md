# SOM-39 · Нативная панель вкладок iOS 26 как в Telegram

Linear: https://linear.app/something-great/issue/SOM-39
Ветка: agent/21-som-39-native-liquid-glass-tabs. Заголовок PR с SOM-39.
Выполнять после брифа 20 этого аккаунта (оба трогают шапку «Сегодня»).

## Решение владельца 05.10.2026

Панель вкладок должна вести себя как в Telegram на iOS 26: настоящий Liquid Glass
системы, а не имитация. Владелец прислал снимок Telegram: плавающая капсула со
вкладками (иконка + подпись), под выбранной — светлая стеклянная «пилюля», бейджи на
иконках, справа — **отдельная круглая стеклянная кнопка**. При нажатии и
протягивании пальцем по вкладкам пилюля следует за пальцем с линзой и упругостью,
отпускание — пружинный доводчик. Это и есть «hover» на телефоне.

Решения владельца:
- отдельная круглая кнопка = **«+» новое занятие** (для тренера); «+» из шапки
  «Сегодня» убрать; у клиента круглой кнопки нет, если для неё нет действия;
- при прокрутке вниз панель **сворачивается** (`minimizeBehavior`), возвращается при
  прокрутке вверх.

Это заменяет самописную панель из ADR 0111 (#86): новый ADR, который её отменяет.

## Подход

- `expo-router/unstable-native-tabs` (`NativeTabs`, expo-router 57, уже установлен):
  на iOS 26 — системный `UITabBar` с Liquid Glass, линзой, протягиванием и
  сворачиванием. Сверь API с `node_modules/expo-router/build/native-tabs/types.d.ts`
  установленной версии: `role`, `minimizeBehavior`, `badgeValue`, `sf`/`src`,
  `tintColor`, `labelVisibilityMode`, `disableTransparentOnScrollEdge`.
- Круглая кнопка: системно отдельной рисуется вкладка с ролью `search`. Проверь, можно
  ли задать ей иконку «plus» и перехватить нажатие (не показывать отдельный экран, а
  открыть создание занятия — тот же маршрут, что у «+» сейчас). Если API этого не
  позволяет — не изобретай обход через приватные API: оставь 5 вкладок, «+» в шапке,
  опиши ограничение в ADR и отчёте. Владелец решит.
- Иконки: SF Symbols, близкие к иконкам прототипа (дом, календарь, люди, стопка/
  книга, человек), или `src` из `prototype-fresh/assets` — выбери одно и обоснуй.
- Бейджи: «Входящие»/«Сегодня» — `badgeValue` только при N > 0 (не «0»).
- Android и web: то, что даёт `NativeTabs` (Material), без падений; iOS < 26 —
  системная панель без стекла.
- Цвета: tint — акцент темы; тёмная и светлая темы.
- Удалить самописную панель, `TabBarSurface`/`TabBarLayout`, ставшие ненужными, и
  ручной нижний отступ, если системная панель сама задаёт safe area/insets; проверь,
  что последний элемент экранов не прячется под панелью.
- Анимации tabPop/индикатора из прототипа для панели больше не нужны — системная
  анимация (отступление от эталона, ADR + UI-PARITY).

## Критерии

- [ ] Тренер: 5 вкладок + отдельная круглая «+» (или задокументированное ограничение);
  клиент: его вкладки без лишней кнопки.
- [ ] Сворачивание при прокрутке на экранах со списками.
- [ ] Бейджи только при N > 0 (тест).
- [ ] «+» из шапки «Сегодня» убран, если круглая кнопка работает.
- [ ] Переходы между вкладками без задержки первого кадра; предзагрузка вкладок из
  ADR 0105 не ломается (или заменена тем, что даёт нативная панель — описать).
- [ ] Reduce motion / «Спокойный интерфейс» — системное поведение, без ошибок.
- [ ] `npm run check` зелёный; отчёт `app/review/21-som-39-native-liquid-glass-tabs/README.md`;
  на iPhone (iOS 26) — «не проверено», это проверит владелец.
- [ ] ADR (отменяет 0111), UI-PARITY, CHANGELOG, ROADMAP.
