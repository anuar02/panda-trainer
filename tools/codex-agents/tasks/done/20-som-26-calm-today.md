# SOM-26 · Перенести спокойный «Сегодня» из эталона в приложение

Linear: https://linear.app/something-great/issue/SOM-26
Ветка: agent/20-som-26-calm-today. Заголовок PR с SOM-26.

## Проверка перед началом

Эталон обновлён PR #87. Если в базе нет `prototype-fresh/css/today-calm.css` и
`docs/app/decisions/0112-calm-today-screen.md` — PR #87 ещё не влит: ничего не меняй,
завершись с ошибкой и сообщением «ждёт #87».

## Решение владельца 05.10.2026

Главный экран тренера разгружен (ADR 0112). Эталон — `prototype-fresh`
(`js/screens/trainer.js`: `todayHeader`, `todayFocus`, `todayRow`, `todayAgenda`,
`todayReplies`; стили `css/today-calm.css`). Приложение повторяет его точно:

- шапка: дата мелко над «Сегодня», «Входящие» с бейджем и «+»; без приветствия и часов;
- блок «Сейчас / Следующее»: метка с остатком времени, крупное `начало – конец`,
  название, участники группы чипами со статусом (подтвердил / ждёт / отменил) или
  программа, флаги только при отклонении от нормы, одна кнопка журнала;
- «Дальше»: лента с колонкой времени и рельсом, каждое занятие **ровно один раз**
  (занятие из блока «Сейчас» в ленте не повторяется), свободное время — пунктирная
  строка с «+», пересечения — как сейчас;
- «Нужен ответ»: каждый запрос, ждущий тренера, одной строкой (день, «перенос»,
  имя, `было → стало`, «Ответить») → тот же лист ответа, что сейчас;
- прошедшие — одна строка «Прошло N занятий» в конце, раскрывается;
- убрать: карточку-сводку с пандой (HeroSummary), «План дня · N», «Индивидуальное»,
  шевроны, «Последнее занятие до …», повторы счётчиков. Панда остаётся в пустом дне
  и празднике.

## Критерии

- [ ] Демо и серверный режим показывают новую раскладку; каждое занятие и каждый
  запрос ровно один раз (тест).
- [ ] Состояния: идёт сейчас / следующее (нет текущего) / все позади / пустой день
  (панда, как сейчас) / загрузка / офлайн / пересечение / отменённое / черновик журнала.
- [ ] Тёмная и светлая темы по spec; вторичный текст `--sec`, не `--ter`; контраст ≥ 4.5:1.
- [ ] Крупный текст: блок «Сейчас» и кнопка журнала не обрезаются.
- [ ] Удалённые элементы не остаются в коде и i18n (мёртвые ключи убрать).
- [ ] Баг с устройства 05.10: при 0 запросов на «Входящих» виден бейдж «0» (и «0 запросов»
  в старой сводке). Бейдж и раздел «Нужен ответ» показываются только при N > 0 (тест).
- [ ] `npm run check` зелёный; отчёт `app/review/20-som-26-calm-today/README.md`
  с парами эталон/приложение (текстом) и «не проверено на iPhone».
- [ ] CHANGELOG, ROADMAP; UI-PARITY — отметить перенос строк из ADR 0112.
