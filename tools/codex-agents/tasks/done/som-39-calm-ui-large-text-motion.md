# SOM-39 · Крупный текст, спокойный интерфейс и движение

Linear: https://linear.app/something-great/issue/SOM-39

## Критерии

- [ ] «Спокойный интерфейс»: настройка в профиле, которая выключает маскота и
  празднования. Экспортировать хук/флаг (например `useCalmMode`), который
  компонент маскота из SOM-38 сможет читать. Сам маскот не реализовывать.
- [ ] Системное «Уменьшение движения»: `AccessibilityInfo.isReduceMotionEnabled`
  и Reanimated `ReduceMotion` для всех анимаций.
- [ ] Крупный текст: системный масштаб шрифта (до 200%) не ломает экраны журнала
  и «Сегодня» — ничего не обрезается и не перекрывается
  (задача 7 из `prototype-fresh/CODEX-PLAN.md`). Добавить тесты рендера с
  увеличенным `fontScale`.
- [ ] Короткие функциональные анимации Reanimated: сохранение подхода, шторки,
  переходы. Длительности и кривые — из прототипа.

## Границы

`app/src/ui/` (типографика, шторки, анимации), экран профиля, экраны журнала и
«Сегодня» — только вёрстка под крупный текст и анимации.
Не трогать: компонент маскота и его ассеты (SOM-38), конструктор шаблонов и
picker (SOM-50), логику расписания и данных, схему Supabase.
