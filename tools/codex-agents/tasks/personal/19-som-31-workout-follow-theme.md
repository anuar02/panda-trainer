# SOM-31 · Журнал тренировки следует теме приложения

Linear: https://linear.app/something-great/issue/SOM-31
Ветка: agent/19-som-31-workout-follow-theme. Заголовок PR с SOM-31.
Выполнять после брифа 18 этого аккаунта (те же файлы).

## Решение владельца 05.10.2026

Журнал тренировки больше **не всегда тёмный**: он следует теме приложения
(Профиль → «Авто / Тёмная / Светлая», `useTheme()` в `app/src/ui/theme.tsx`).
Это меняет правило «журнал всегда тёмный» в ADR 0007, `docs/app/UI-PARITY.md` (стр. 13),
`docs/app/PROJECT-MEMORY.md` (стр. 151) и `docs/app/OPEN-QUESTIONS.md` (стр. 91) — обнови
их и создай новый ADR, который заменяет это правило.

## Контекст

- Тёмные цвета зашиты в `app/src/features/workout/measurements.ts` (`#0b0c0e`, `#151619`,
  `#1d1e23`, `#f2f2f3`, `#a3a4ab`, `#8c9eff`, `#6f86ff` …) и местами в
  `workout-screen.tsx` (`#ffffff` на акцентах — допустимо, если это текст на акценте).
- Те же стили использует `app/src/features/workout-entry/screen.tsx`.
- Светлые значения бери из токенов темы (`app/src/ui/tokens.json`, `colors.light`) и
  из светлой темы прототипа для тех же ролей (поверхность, приподнятая поверхность,
  граница, вторичный текст, акцент); тёмная тема должна остаться визуально как сейчас.

## Критерии

- [ ] Все цвета журнала, ввода подходов, отдыха, dock, шторок журнала и экрана
  входа в тренировку берутся из темы; хардкод остаётся только для текста на акценте.
- [ ] Тёмная тема — пиксель-в-пиксель как до изменения (сравни значения стилей тестом).
- [ ] Светлая тема: контраст текста ≥ 4.5:1 (есть `tests/contrast.test.ts` — добавь роли
  журнала), состояния выбранного/выполненного подхода различимы.
- [ ] Статус-бар меняет стиль вместе с темой на экране журнала.
- [ ] Тесты: стиль строится для обеих тем; контраст; `npm run check` зелёный.
- [ ] ADR (заменяет правило 0007), обновлённые UI-PARITY/PROJECT-MEMORY/OPEN-QUESTIONS,
  CHANGELOG, ROADMAP, отчёт `app/review/19-som-31-workout-follow-theme/README.md`.

## Границы

`app/src/features/workout/**`, `app/src/features/workout-entry/**`, при необходимости
новые роли в `app/src/ui/tokens.json` (только добавление), тесты контраста, docs.
Не трогать навигацию, создание занятия, `motion.tsx` (ADR 0107).
