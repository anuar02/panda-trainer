# SOM-31 · Активное упражнение целиком на экране без прокрутки

Linear: https://linear.app/something-great/issue/SOM-31
Ветка: agent/18-som-31-workout-active-exercise-fit. Заголовок PR с SOM-31.

## Решение владельца 05.10.2026

В активной тренировке **текущее упражнение должно быть ровно в кадре**: всё, что
нужно для записи подхода, видно сразу, без ручной прокрутки. Отступление от
раскладки `prototype-fresh` допустимо — запиши в ADR и UI-PARITY.

## Контекст

- `app/src/features/workout/workout-screen.tsx` — `WorkoutScreen` (L68–L1092),
  `ScrollView` с `ref={scroll}`, фокус упражнения: `focused` / `setFocused`
  (runtime или локальный).
- Размеры: `getWorkoutStyles(fontScale, width)` в `app/src/features/workout/measurements.ts:406`;
  крупный текст: `fontScale > 1.3 || width < 360`.
- Нижний dock журнала и шторки — учитывать как занятое место.

## Критерии

- [ ] При открытии тренировки и при смене активного упражнения (отметка подхода,
  переход к следующему, выбор вручную) карточка активного упражнения выравнивается
  под шапкой (плавная прокрутка; при reduce motion — без анимации).
- [ ] Карточка активного упражнения — название, текущий подход, поля веса/повторов,
  кнопка записи — помещается между шапкой и dock на 393×852 (iPhone 14 Pro) и
  375×667 (SE): уплотнить именно активную карточку (свернуть выполненные подходы,
  компактнее отступы), а не мельчить шрифты.
- [ ] Крупный текст: если не помещается — активные поля и кнопка записи остаются
  видимыми, прокручивается остальное (опиши правило в ADR).
- [ ] Ручная прокрутка пользователем не перебивается автопрокруткой, пока он
  листает; автовыравнивание — только на события выше.
- [ ] Тесты: выравнивание вызывается на смену фокуса; расчёт помещается/не помещается
  для двух размеров экрана. `npm run check` зелёный.
- [ ] ADR, UI-PARITY, CHANGELOG, ROADMAP, отчёт `app/review/18-som-31-workout-active-exercise-fit/README.md`
  с замерами по размерам экрана (расчётными) и «не проверено на iPhone».

## Границы

`app/src/features/workout/**`, `app/src/features/workout-entry/**` — только раскладка,
тесты, docs. Не менять цвета/тему (это следующий бриф 19 того же аккаунта), навигацию,
создание занятия, `motion.tsx` (только `AnimatedView`/`AnimatedPressableView`, ADR 0107).
