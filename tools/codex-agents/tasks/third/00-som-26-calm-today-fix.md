Linear: https://linear.app/something-great/issue/SOM-26
Ветка: agent/00-som-26-calm-today-fix. Заголовок PR с SOM-26.

## Контекст

Координатор проверил влитый #88 (`d79cef9`) против брифа
`20-som-26-calm-today.md`: app/database CI зелёный, CHANGELOG и отчёт есть,
но добавлены 12 PNG в `app/review/20-som-26-calm-today/parity/generated/`.
Это прямо нарушает ADR 0066 и RULES. Отчёт ошибочно утверждает
«PNG не коммитятся». Нужен отдельный исправляющий PR, без отката реализации
«Сегодня» и без переписывания истории git.

Это приоритетное исправление уже влитой задачи, а не новая часть реализации.
Если бриф 21 уже выполняется, сначала заверши его; затем возьми этот файл
первым следующим. Файлы реализации навигации и шапки не трогать.

- [ ] В текущем дереве git нет 12 PNG, добавленных #88 под каталогом
  `app/review/20-som-26-calm-today/parity/generated/` (6 app + 6 reference).
  При необходимости сохрани локальную копию вне репозитория до удаления.
- [ ] Удалены generated HTML/JSON и дубли spec из этого каталога, если они
  остаются лишь индексами удалённых снимков. Канонические полные
  `prototype-fresh/review/parity/spec-{dark,light}.json` сохранены.
- [ ] Отчёт `app/review/20-som-26-calm-today/README.md` честно объясняет ошибочное
  включение снимков в #88 и их удаление отдельным PR; текстовые пары, точные
  исторические команды/результаты и native-ограничения сохранены. Пути к
  локальным снимкам не выдаются за доступные версионированные артефакты.
- [ ] CHANGELOG и ROADMAP содержат краткую запись исправления; новый текстовый
  отчёт `app/review/00-som-26-calm-today-fix/README.md` содержит точные проверки.
- [ ] Diff ограничен артефактами и документацией; новых PNG/бинарных снимков нет,
  код, поведение, зависимости и migration не меняются. Проверены
  `git diff --check` и список tracked-файлов. Обязательные проверки по RULES
  выполняет рабочий; координатор зелёный CI #88 уже проверил и не повторяет.
- [ ] Экран и задача целиком не объявлены принятыми; native и одобрение
  владельца остаются открытыми.
