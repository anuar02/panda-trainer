# SOM-26 · «Сегодня»: завершённые занятия — в «Прошло», без противоречий

Linear: https://linear.app/something-great/issue/SOM-26
Ветка: agent/22-som-26-today-finished-sessions. Заголовок PR с SOM-26.
Выполнять после брифа 21 этого аккаунта (тот же экран).

## Баг с iPhone владельца 05.10.2026

Демо, сейчас 20:30, журналы занятий 20:00 «Мини-группа» и 21:15 «Айгерим» завершены.
Экран показывает одновременно «Все занятия на сегодня позади» и ленту «Дальше» с
этими двумя занятиями (флаг «Журнал завершён»), а метка ленты — «до 19:30».

Причины (`app/src/features/trainer-today/trainer-today-screen.tsx`):
- `{!focus && live.length > 0 && allPast}` (≈L784) — сообщение показывается, даже
  когда лента не пуста;
- «до …» (≈L799) считается по `live`, где завершённые журналы исключены, а в ленте
  они остаются. В эталоне (`prototype-fresh/js/screens/trainer.js`, `todayAgenda`,
  `lastEnd`) та же ошибка с «до …».

## Правило (решение владельца)

Занятие с завершённым журналом считается прошедшим: оно уходит в свёрнутое
«Прошло N занятий» (там флаг «Журнал завершён» уместен) и не попадает ни в блок
«Сейчас», ни в «Дальше». Блок «Сейчас/Следующее» — первое незавершённое.

## Критерии

- [ ] Эталон и приложение (демо + серверный режим) применяют правило одинаково.
- [ ] «Все занятия на сегодня позади» — только когда нет ни блока «Сейчас», ни ленты.
- [ ] «до HH:MM» — конец последнего неотменённого занятия, показанного в ленте; нет
  ленты — нет метки.
- [ ] Счётчик «Прошло N» включает занятия с завершённым журналом.
- [ ] Тесты: сценарий владельца выше (оба журнала завершены в 20:30) → нет ленты,
  есть «позади» и «Прошло 7»; частичный случай (завершено текущее, впереди есть
  незавершённое) → блок «Следующее» на нём; «до …» совпадает с последней строкой ленты.
  Тест эталона в `prototype-fresh/tests/` и тест приложения.
- [ ] `node --test prototype-fresh/tests/*.test.cjs` и `npm run check` зелёные;
  CHANGELOG, ROADMAP; отчёт `app/review/22-som-26-today-finished-sessions/README.md`.
