# SOM-26 · Время занятия — отдельным шагом после даты

Linear: https://linear.app/something-great/issue/SOM-26
Ветка: agent/18-som-26-schedule-time-step. Заголовок PR с SOM-26.

## Решение владельца 05.10.2026

При создании занятия **время выбирается на отдельном шаге после даты**, а не на
одном экране с датой. Это отступление от `prototype-fresh` — запиши в ADR и в
`docs/app/UI-PARITY.md` как исключение владельца. Тексты, вид чипов и строк —
как сейчас.

## Контекст

- `app/src/features/session-editor/create-session-screen.tsx`: шаги
  `['clients', 'time', 'program']` (≈L154); шаг 1 сейчас содержит дату (`dateOptions`,
  ChoiceRow), «Начало» (`times`, EditorChip) и «Длительность».
- Обёртка сервера: `app/src/features/workspace-scheduling/workspace-create-session-screen.tsx`.
- Проверь, использует ли тот же компонент/шаги перенос занятия (SOM-27,
  `grep -rn "CreateSessionScreen\|sessionEditor.date" app/src`). Если да — то же
  разделение и там; если нет — не трогать.

## Критерии

- [ ] Шаги: Клиенты → **Дата** → **Время** (начало + длительность) → Программа;
  чипы шагов показывают 4 шага, переход назад по чипу сохраняет выбранное.
- [ ] Выбор даты переводит на шаг «Время» (или кнопка «Далее» — как остальные
  шаги в этом редакторе; выбери то, что уже принято в нём, и опиши в ADR).
- [ ] На шаге «Время» видна выбранная дата (подзаголовок/строка), её можно сменить,
  вернувшись на шаг «Дата».
- [ ] Смена даты сбрасывает время, только если оно стало недоступным
  (прошедшее сегодня / пересечение); иначе время сохраняется.
- [ ] Восстановление черновика, ошибки пересечения, офлайн и повтор — без регрессий.
- [ ] i18n: новые строки только через ru-ресурсы; без хардкода.
- [ ] Тесты на порядок шагов, переходы и сохранение черновика; `npm run check` зелёный.
- [ ] ADR, UI-PARITY, CHANGELOG, ROADMAP, отчёт `app/review/18-som-26-schedule-time-step/README.md`.

## Границы

`app/src/features/session-editor/**`, `app/src/features/workspace-scheduling/**` — только
то, что нужно для шагов, i18n-ключи редактора, тесты, docs/ADR/UI-PARITY/CHANGELOG/ROADMAP.
Не трогать навигацию (`app/src/features/navigation/**`), журнал тренировки и `motion.tsx`.
Анимированные стили — только через `AnimatedView`/`AnimatedPressableView` (ADR 0107).
