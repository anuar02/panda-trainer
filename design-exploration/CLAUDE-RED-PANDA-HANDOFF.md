## Решение пользователя

Главный маскот — **красная панда с тёмно-коричневой повязкой**. Подробности и что сохранять —
[MASCOT-DECISION.md](MASCOT-DECISION.md). Мастер-лист (4 ракурса, 8 эмоций, 7 поз):
[mascot-sheets-2026-09-26/red-panda-dark-headband.png](mascot-sheets-2026-09-26/red-panda-dark-headband.png).

Как пришли к выбору: пользователь отказался от рыси №7 («думай заново») и попросил маскота,
рассчитанного на плавную анимацию уровня Duolingo/Headspace (качество, не стиль).
Кастинг 8 зверьков по простым формам → шорт-лист выдра / красная панда → листы персонажей →
проверка трёх цветов повязки (оранжевая сливается с головой, кремовая — с белыми отметинами)
→ выбрана панда с тёмной повязкой; оранжевый `#FF7A1F` только на напульснике.

## Как работать с пользователем

- Картинки генерирует пользователь сам (ChatGPT / GPT Image, иногда через Codex).
  От Claude ждут **готовые промпты**, а не собственную генерацию. Промпты — на английском,
  с приложенным мастер-листом как референсом.
- Пользователь хочет видеть готовый результат, а не череду черновиков; терпение к итерациям
  «рисования вслепую» закончилось.
- Параллельно в репо работает Codex — перед правкой файла проверить, не менял ли он его.

## Открытые варианты (пользователь не выбрал)

1. **Meshy (последнее обсуждение).** Пользователь генерирует 3D: A-поза по мастеру → Image to 3D →
   Auto-Rig → 3–5 движений (idle, wave, jump, cheer) → GLB в `design-exploration/red-panda-3d/`.
   Claude делает страницу-просмотрщик на Three.js в том же макете телефона
   (кнопки движений, crossfade, вращение пальцем). Ограничения, о которых сказано:
   лицо не анимируется (запечено в текстуру), движения «человеческие» mocap,
   стиль станет объёмным. Промпт для A-позы уже выдан пользователю:
   > Using the attached red panda (dark-brown headband version) as the exact reference, draw the same character as a single full-body front view in a neutral A-pose for 3D modeling: standing straight, arms slightly away from the body (about 30°), legs slightly apart, tail visible to the side, neutral friendly face with eyes open. Same flat colors and proportions. Plain white background, no shadow, no text.
2. **Rive** — так делают Duolingo: иллюстратор/аниматор ригует визуально, файл подключается
   в iOS/Android/RN/web. Упрощённая схема из `index.html` — годная стартовая структура.
3. **Статичные позы в прототипе** вместо рыси — предложено, ответа нет.
   Ассеты рыси и `prototype/js/mascot.js` пока не трогались.
