# Выдра и красная панда — листы для сравнения

26 сентября 2026. Созданы встроенным image_gen по референсу `../mascot-casting-2026-09-26/eight-candidates.png`. Точные промпты и уточнения — в `prompts.json`.

- `otter-sheet.png`: выдра №1; тёплое коричневое тело, кремовые морда и живот, более светлые лапы, оранжевые повязка и напульсник.
- `red-panda-sheet.png`: красная панда №2; более глубокий ржаво-красный, тёмно-коричневые конечности, более светлые лапы, оранжевые повязка и напульсник.

На каждом листе 19 рисунков, слева направо:

1. Четыре ракурса: анфас, 3/4, профиль, со спины.
2. Восемь эмоций: нейтральная, радость, восторг, гордость, сонливость, задумчивость, удивление, мягкое беспокойство.
3. Семь поз: приветствие, большой палец вверх, прыжок, ожидание сидя, планшет для записей, растяжка, отдых.

Это статичные растровые концепты для разбора, без разделения на части и без Rive-рига. Сходство поз проверено визуально; читаемость эмоций при 48 px ещё не проверена. При подготовке векторов нужно нормализовать оставшиеся тональные переходы, пропорции между позами и положение аксессуаров. В частности, в позе растяжки у выдры виден дополнительный напульсник.

Этот сравнительный проход сам по себе не меняет сохранённое решение о главном маскоте.
