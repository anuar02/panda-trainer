# Дизайн-система

Дизайн-язык перенесён из референса **gymGO** (Revolut-DNA: светлый, монохромный
интерфейс, семантический цвет только для состояния, один тёплый акцент бренда).

**Точка правды:** `gymGO (2)/src/src_ui.jsx` (объект `T`) и
`gymGO (2)/Design System.md`. Значения ниже — дословный перенос; в CSS они лежат
в `prototype/css/tokens.css`.

> Референс — образец вкуса и хореографии. Продуктовые сценарии gymGO
> (клуб, турникет, QR-проход, рейтинг) не переносятся.

## 1. Цвет

### Поверхности
| Токен | Значение | Роль |
| --- | --- | --- |
| `--canvas` | `#f6f6f7` | фон приложения |
| `--surface` | `#ffffff` | карточки, шторки, бары |
| `--sunken` | `#eeeef0` | треки, мягкие заливки, поля |
| `--scrim` | `rgba(8,8,10,.42)` | затемнение под шторкой |

### Текст и границы
| Токен | Значение | Роль |
| --- | --- | --- |
| `--ink` | `#050505` | основной текст, заливка CTA |
| `--sec` | `#5e5f60` | вторичный текст, метаданные |
| `--ter` | `#9ba1a8` | третичный (см. §6 — область применения ограничена) |
| `--border` | `#e9e9ec` | границы полей, дни недели |
| `--hair` | `#f0f0f2` | разделители строк |

### Семантические (только состояние)
| Токен | База | Soft | Ink (для текста) |
| --- | --- | --- | --- |
| Mint — успех/активно | `#10c22b` | `.10` | `#0a8a23` |
| Amber — предупреждение | `#f3b84a` | `.16` | `#8a6410` |
| Danger — ошибка | `#c22b10` | `.08` | `#c22b10` |

### Ember — серии и маскот
`#ffb23d → #ff7a1f → #f0420f`, glow `rgba(255,120,40,.55)`.
В объёме первой версии серий и маскота нет, поэтому ember **не используется**.
Правило: не добавлять ember туда, где нет серии.

**Правило цвета:** приложение монохромно по умолчанию; mint/amber/danger
появляются только чтобы обозначить состояние. Цвет никогда не является
единственным носителем смысла — рядом всегда текст или иконка.

## 2. Типографика

- UI-текст: **Inter** (`--ui`), fallback `system-ui, sans-serif`.
- Заголовки и крупные числа: **Montserrat** (`--disp`), вес 700–900,
  плотный трекинг (−0.2…−0.6px).
- Числа: `font-variant-numeric: tabular-nums` (класс `.num`).

Ориентиры размеров:

| Элемент | Шрифт | Размер / вес |
| --- | --- | --- |
| PageTitle (крупный) | Montserrat | 32 / 800, line-height 1.04 |
| PageTitle (компактный) | Montserrat | 27 / 800 |
| Section header | Montserrat | 21 / 800 |
| Заголовок шторки | Montserrat | 23 / 800 |
| Название карточки/клиента | Montserrat | 22 / 800 |
| Крупное число (ввод) | Montserrat | 54 / 900, −2px |
| Строка списка | Inter | 15.5 / 600 |
| Метаданные строки | Inter | 13 / 500 |
| Кнопка | Inter | 16.5 / 700 |

## 5. Моушн

| Событие | Кривая | Длительность |
| --- | --- | --- |
| Стандарт (прогресс, трансформация) | `cubic-bezier(.2,.7,.2,1)` | 160–400 мс |
| Шторка | `cubic-bezier(.22,.8,.25,1)` | 340 мс |
| Пульс живой точки | `ease-in-out` | 2.4 с, бесконечно |
| Появление тоста | стандарт | 240 мс |

Принцип: анимация — ответ на событие, а не постоянный фон. Всё отключается при
`prefers-reduced-motion: reduce` (см. `base.css` и `components.css`).

## 6. Доступность и осознанные отступления

Прототип приоритизирует требования `trainer-design-handoff-v2.md`, поэтому в
двух местах **сознательно отличается** от референса:

1. **`--ter` (#9ba1a8) не используется для значимых метаданных.**
   В референсе `Row.meta` набран `--ter`. Здесь метаданные строк — `--sec`
   (`#5e5f60`, контраст ≈ 5.7:1 на белом против ≈ 2.7:1 у `--ter`).
   `--ter` оставлен для декоративных подсказок: шевроны, номера упражнений,
   заголовки дней недели, необязательные подписи.
2. **Семантический цвет не используется для текста напрямую.**
   Текст на мягкой заливке берёт `--mint-ink` / `--amber-ink`; базы `--mint` /
   `--amber` — только заливки и графические элементы.

Дополнительно:
- Фокус: `:focus-visible` — контур `2.5px var(--ink)` с отступом 2px.
- Интерактивные `div` несут `role="button"` и реагируют на Enter/Space.
- Иконочные кнопки имеют `aria-label` / `title`.
- Пересекающиеся занятия — **разные строки внутри рамки**, не одна запись:
  цвет рамки не единственный носитель смысла, рядом подпись «Пересечение».
- Пустое состояние никогда не изображает отсутствие данных нулём (см. Прогресс).

## 7. Как расширять

1. Сначала зафиксируйте решение в `DESIGN.md`.
2. Добавьте токен в `tokens.css` с комментарием о роли.
3. Добавьте компонент в `components.css`, отметив, если он специфичен для
   продукта (секция «TrainerApp-specific components»).
4. Не переиспользуйте семантические токены вне их роли и не вводите «средний»
   цвет-компромисс.
