Уточнение владельца от 01.10.2026: коммит не является поводом заканчивать работу
и ждать очередного «continue». После законченного пакета продолжать следующую
разрешённую незаблокированную задачу. Останавливаться, когда дальнейшая работа
требует решения владельца или неустранимого внешнего действия; не выдавать
промежуточный checkpoint за завершение всего запроса.

01.10.2026 владелец отменил требование о частых обновлениях Linear после каждой
задачи: не нужно писать в Linear каждый раз. Продолжать фиксировать технические
решения и проверки в репозитории; это предпочтение не меняет отдельное разрешение,
необходимое для комментариев и сообщений людям.

Предпочтение владельца от 01.10.2026: после каждой выполненной задачи делать
git commit без повторного запроса разрешения. Перед коммитом выполнить нужные
проверки, включать только относящиеся к задаче изменения и сообщать hash коммита.
Если реализация и проверки завершены, но визуальная приёмка владельца или другая
часть Linear issue остаётся открытой, коммитить законченный пакет с честным
описанием оставшегося; не оставлять готовую работу незакоммиченной из-за ожидания
приёмки. Коммит сам по себе не закрывает issue. Это правило не требует push.
