# 0064. Регион данных пилота, сроки хранения и домен приглашений

- **Статус:** Принято
- **Дата:** 03.10.2026
- **Кто решил:** владелец продукта

## Контекст

Открытые вопросы №1 (SOM-51), №9 (SOM-59) и №10 (SOM-60) блокировали
окружение пилота (SOM-40), экспорт и удаление аккаунта (SOM-41) и боевые ссылки
приглашений (SOM-19/21). Варианты размещения — `prototype-fresh/SYNC-DESIGN.md`,
раздел «Варианты хранения вне браузера». Бюджет (вопрос №2, SOM-52) — ADR 0067.

## Решение

1. **Регион (SOM-51).** База, резервные копии и логи пилота — Supabase Cloud,
   регион EU Central (Франкфурт), отдельный проект от разработки. Реальные данные
   клиентов загружаются только после того, как профильный специалист подтвердит
   допустимость хранения вне Казахстана. До подтверждения — только вымышленные
   данные или данные участников с явного согласия по отдельному решению владельца.
2. **Сроки хранения (SOM-59).** Данные хранятся, пока существует аккаунт тренера.
   При удалении аккаунта данные удаляются; из резервных копий они уходят по мере их
   ротации, не позднее 7 дней. Несинхронизированные записи на потерянном или
   сломанном телефоне не восстанавливаются; приложение показывает «Сохранено на
   телефоне» / «Синхронизировано» (ADR 0062).
3. **Домен приглашений (SOM-60).** Уточнено владельцем 03.10.2026: домен
   `narutouzumaki.kz` занят другим проектом, поэтому проект получает поддомен
   первого уровня `trainer.narutouzumaki.kz` (DNS в Cloudflare).
   - Ссылки приглашений: `https://trainer.narutouzumaki.kz/invite/<token>` на
     Cloudflare Pages, там же `/.well-known/apple-app-site-association` и
     `/.well-known/assetlinks.json` для открытия ссылки в приложении.
   - Письма (OTP, приглашения): `no-reply@trainer.narutouzumaki.kz` через
     бесплатный SMTP-сервис; записи SPF/DKIM — в зоне Cloudflare. Встроенный SMTP
     Supabase не подходит: шлёт только на адреса команды проекта.
   - Поддомены второго уровня (`invite.trainer…`) не используются: бесплатный
     сертификат Cloudflare покрывает только `*.narutouzumaki.kz`.
   - API остаётся на адресе Supabase: свой домен API платный.

## Рассмотренные варианты

- Хранение только в Казахстане — Supabase там нет; самостоятельное размещение
  требует эксплуатации серверов, бэкапов и обновлений.
- Автоудаление после неактивности — нужны предупреждения и отдельная работа.
- Свой домен сразу — лишние расходы и настройка до проверки продукта.

## Последствия

SOM-41 (экспорт, удаление аккаунта, политика конфиденциальности) может
строиться на правиле хранения из п. 2. Бюджет — только бесплатные тарифы (ADR 0067):
бэкапы делаются своим ночным дампом с проверкой восстановления.
Настройка поддомена и SMTP требует аккаунтов владельца.
