# 0019. Локальный конструктор шаблонов и снимок плана занятия

- **Статус:** Принято для локального демо
- **Дата:** 30.09.2026
- **Основание:** продолжение шаблонов по каноническому prototype-fresh, ADR 0015/0018.

## Решение

Чистый `domain/templates` проверяет название, уникальность, количество упражнений,
подходы, диапазон повторений/секунд, вес и отдых по правилам TemplateRepository
прототипа. Конструктор сохраняет один незавершённый черновик; новая операция при
его наличии предлагает продолжить его либо заменить. Копия получает новый ID,
редактирование сохраняет исходный ID. Исходные fixtures не мутируют.

Общий `TemplateProvider` хранит пользовательские шаблоны и черновик в одном
версионированном документе AsyncStorage (`panda:demo:templates:v1`). Последовательная
очередь исключает перестановку записей. Сохранённый шаблон становится доступен
другим экранам только после успешной записи; при ошибке черновик остаётся в памяти,
ошибка видна, доступен повтор. Ошибка чтения блокирует запись до успешного чтения.
Это продолжение существующего демо-хранилища, без новой зависимости.

Library, detail и wizard читают общий каталог. При создании занятия из изменённого
или нового шаблона расписание сохраняет `planSnapshot` с упражнениями, единицами,
подходами, повторами, весом и отдыхом. Журнал получает упражнения из этого снимка;
повторная загрузка не требует наличия исходного шаблона. Более позднее изменение
имени или нагрузки шаблона не переписывает уже созданное занятие и его результаты.
Старые сохранения без снимка используют существующие встроенные программы.

## Альтернативы и границы

Глобальная мутация fixtures связывала бы историю со свежей редакцией шаблона.
Отдельная запись черновика и шаблонов могла бы восстановить уже сохранённый
черновик после частичной ошибки; выбран один документ.

Это не Supabase, не production offline-sync, не версионирование личных программ
клиентов. Роль локального демо не является границей серверной безопасности.
Серверная схема этапа 3, назначение личных программ, паритет шторок, доступность
и визуальное одобрение владельца остаются открытыми.
