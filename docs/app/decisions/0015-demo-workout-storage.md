# 0015. Общий локальный журнал демоверсии

- **Статус:** Принято для демо, не для production-sync
- **Дата:** 30.09.2026
- **Кто решил:** исполнитель в рамках переноса прототипа

## Контекст

Today и Schedule должны открывать один и тот же журнал занятия. Изолированный
state экрана теряет черновики при навигации и не позволяет вернуться через dock.
Нужен проверяемый демо-сценарий до подключения реальных клиентов и backend.

## Решение

Чистый `domain/workout` содержит канонические вымышленные занятия и immutable
reducer. `WorkoutDemoProvider` живёт над навигацией и хранит журналы по sessionId,
результаты и черновики — отдельно по участнику, упражнению и подходу.
Существующий AsyncStorage сохраняет версионированный снимок под отдельным ключом
`panda-trainer.demo-workouts.v1`. Записи выполняются последовательно; только
завершение последней записи меняет видимый статус сохранения.

До окончания чтения редактирование заблокировано. Повреждённая или неизвестная
версия не заменяется пустым состоянием и не перезаписывается. Ошибка записи
сохраняет актуальный снимок в памяти, показывает предупреждение и повтор.
Завершение частичного журнала требует подтверждения; черновик не является
результатом. Завершённые журналы доступны только для чтения.

## Альтернативы и границы

- State внутри экранов не обеспечивает связность и восстановление.
- Production SQLite/outbox не подменяется этим адаптером: ADR 0003 остаётся
  отдельным предложенным решением с транзакциями и серверной идемпотентностью.
- AsyncStorage-снимок — один локальный экземпляр демо, без синхронизации устройств,
  конфликтов вкладок и гарантии записи при аварийном закрытии до завершения I/O.
- Посещение, списание пакета и серверные записи не меняются. Новых зависимостей,
  платных сервисов и реальных клиентских данных нет.

## Проверка

Domain-тесты проверяют изоляцию, ввод, завершение и декодирование. Provider-тесты
проверяют гидратацию, восстановление, повреждённые данные, очередь и retry.
Снимки и browser/native-сценарии подтверждают отдельные проверки, но не заменяют
визуальную приёмку владельцем по ADR 0007.
