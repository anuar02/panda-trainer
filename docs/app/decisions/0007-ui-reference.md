# 0007. Эталон интерфейса — prototype-fresh в виде по умолчанию

- **Статус:** Принято; правило «журнал всегда тёмный» заменено [ADR 0109](0109-workout-follows-app-theme.md) 05.10.2026
- **Дата:** 29.09.2026
- **Кто решил:** владелец продукта

## Контекст

Каркас этапа 1 взял палитру «Чернила», но вкладки, панель вкладок, кнопки, радиусы,
кегли, иконки и тема по умолчанию разошлись с прототипом. В прототипе несколько
оформлений (`?visual=instrument`, `?visual=firm`) и палитр, и не было записано, какое из
них переносится. Без явного эталона и проверки приложение продолжит расходиться.

## Решение

- Эталон — `prototype-fresh/index.html` без параметров: вид по умолчанию, палитра
  «Чернила», ширина 390.
- Тема по умолчанию — «по роли», как в прототипе: тренер тёмная, клиент светлая,
  журнал тренировки всегда тёмный; в профиле «Авто / Тёмная / Светлая».
- Числа (цвета, радиусы, кегли, отступы, тени) берутся из вычисленных стилей прототипа
  `prototype-fresh/review/parity/spec-*.json`, снятых скриптом `capture.cjs`.
- Экран готов только после сверки с эталоном по [UI-PARITY.md](../UI-PARITY.md) и
  одобрения владельцем. Отклонения — только из таблицы разрешённых.

## Рассмотренные варианты

- **«Инструмент»** (`?visual=instrument`) — графит и оранжевый акцент; не выбран владельцем.
- **Тема по системной настройке** — текущее поведение каркаса; заменено правилом «по роли».
- **Сверка «на глаз» по старым снимкам** — даёт дрейф; заменена замерами и парами снимков.

## Последствия

- Каркас этапа 1 требует доработки (вкладки, панель вкладок, токены, шрифты, иконки,
  тема) — PR D в [handoff](../CODEX-STAGE-1-FIXES-HANDOFF.md).
- Каждый PR с экраном несёт пары снимков и чек-лист паритета; ревью дольше, но
  расхождения видны сразу.
- Изменение эталона — новое решение владельца и перезапуск `capture.cjs`.
