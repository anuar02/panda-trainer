# 0101. Удаление аккаунта клиента сохраняет историю у тренеров

- **Статус:** Принято (продуктовое правило; юридическая проверка остаётся отдельным gate)
- **Дата:** 04.10.2026
- **Кто решил:** владелец продукта

## Контекст

SOM-41. Клиентский аккаунт может быть привязан к карточкам нескольких тренеров;
один человек может быть и тренером, и клиентом. Нужно правило, что происходит
с историей при удалении аккаунта ([DELETION-PREFLIGHT-CONTRACT](../privacy/DELETION-PREFLIGHT-CONTRACT.md),
[DATA-LIFECYCLE](../privacy/DATA-LIFECYCLE.md)).

## Решение

Удаление аккаунта клиента удаляет его вход и личные данные аккаунта (Auth,
profile, push-устройства, приглашения/связи как пользователя). Карточка клиента
у **каждого** тренера сохраняется как карточка «без приложения» вместе с историей
занятий, журналов и оплат — это рабочие записи тренера. Данные других тренеров
не затрагиваются; один тренер никогда не удаляет чужие данные.

Если человек одновременно тренер и клиент, удаление аккаунта удаляет его
пространство тренера по правилам удаления тренера и отвязывает его клиентские
карточки у других тренеров по правилу выше.

## Рассмотренные варианты

- Удалять вместе с аккаунтом все карточки и историю у всех тренеров — отклонено:
  уничтожает финансовые и рабочие записи других людей.
- Отложить до юриста — не выбрано: продуктовое правило зафиксировано сейчас,
  юридическая проверка выполняется до пилота на реальных данных.

## Последствия

Удаление аккаунта клиента реализуемо как отвязка карточек без каскада по чужим
workspace. До реальных данных обязательна проверка специалистом (ADR 0064):
правовые основания, сроки, права субъекта, обезличивание оставшихся записей.
