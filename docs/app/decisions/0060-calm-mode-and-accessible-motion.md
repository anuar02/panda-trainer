# 0060. Настройка спокойного интерфейса и доступное движение

- **Статус:** Реализовано; визуальная и нативная приёмка открыты
- **Дата:** 03.10.2026
- **Задача:** SOM-39

## Решение

`CalmModeProvider` внутри общего `ThemeProvider` хранит настройку отдельно для
тренера и клиента на устройстве (`panda-trainer.calm.trainer` / `.client`).
Это соответствует раздельным переключателям из CODEX-PLAN §2; схема Supabase
и бизнес-данные не меняются. Последовательные записи AsyncStorage сохраняют
порядок быстрых переключений; позднее чтение не заменяет выбор пользователя.
Ошибка чтения/записи видна в профиле; переключение повторяет запись.

SOM-38 получает `useCalmMode(): boolean`. `useCalmModePreference()` предоставляет
управление, readiness и ошибку; `useCelebrationsEnabled()` запрещает празднования
до чтения настройки и при calm mode. Сам компонент/ассеты маскота не изменяются.
Существующие изображения в Today и кнопке голоса журнала скрываются. Бриф SOM-39
требует выключения маскота, поэтому скрывается и изображение пустого Today
(старый CODEX-PLAN оставлял статичную позу); это обратимое поведение по текущему
прямому поручению владельца, без изменения прототипа.

`useSystemReduceMotion()` читает AccessibilityInfo и подписывается на изменения.
До ответа/при ошибке движение выключено. Системное событие имеет приоритет над
поздним начальным ответом. MotionView использует withTiming / ReduceMotion.System;
при включении reduce motion сразу устанавливает конечное состояние. Sheet
передаёт System либо Always в overrideReduceMotion, включая изменения во время
сессии. Предпочтение calm не выключает функциональные действия и не подменяет
системное reduce motion.

## Числа и визуальная проверка

- Sheet: 420 ms, cubic-bezier(.22, 1, .36, 1), из переменных spec-dark/light.json.
- Появление/смена упражнения: riseIn, 600 ms, смещение 14 px, кривая
  cubic-bezier(.2, .8, .2, 1) из fresh.css и spec-dark/light.json.
- Запись подхода: opacity .4 → 1, 200 ms из функционального recorded в
  instrument.css:153–156, с общей кривой **эталона по умолчанию**. В default CSS
  нет определения is-set-recorded, хотя app.js добавляет этот класс. Этот перенос
  сохраняет короткую функциональную обратную связь, но его приёмка владельцем
  остаётся открытой; вопрос записан в OPEN-QUESTIONS.

При fontScale > 1.3 (включая 20/15 и 200%) либо ширине < 360 тесные строки Today
становятся вертикальными, поля журнала растут, действия журнала входят в
ScrollView. Стандартные размеры типографики не уменьшаются, системное
масштабирование не ограничивается. Jest проверяет структуру/действия, но не
измеряет нативный layout, поэтому успешные тесты не подтверждают отсутствие
обрезания на iOS/Android.
