# 0004. Вход: e-mail OTP, Apple, Google

- **Статус:** Способы входа подтверждены владельцем; домен приглашений отложен
- **Дата:** 29.09.2026
- **Кто решил:** владелец, 01.10.2026 в ответе на вопрос SOM-60:
  «Confirm email code + Apple + Google». На вопрос о домене: «pending».

## Контекст

Нужны настоящие учётные записи для тренера и клиента, принятие приглашения по ссылке
и восстановление доступа на новом телефоне. В Казахстане привычен вход по номеру
телефона, но SMS платные и требуют отдельного поставщика.

## Решение

- Supabase Auth: одноразовый код на e-mail (без пароля).
- Sign in with Apple и Google. Apple обязателен в App Store, если есть вход через Google.
- Приглашение: ссылка `https://…/invite/<token>` открывает приложение (deep link Expo
  Router); после входа RPC `accept_invitation` привязывает аккаунт к карточке клиента.
- Сессия — в `expo-secure-store`.

Подтверждение способов входа позволяет продолжить SOM-19. Домен приглашений
ещё не выбран: production invite links не конфигурируются. Это не разрешение
на платный SMTP, Apple Developer subscription или отправку писем реальным людям.

## Рассмотренные варианты

- **Телефон + SMS OTP** — привычнее, но стоимость SMS и выбор поставщика; вернуться
  после пилота.
- **Пароль** — лишние сбросы паролей, хуже для клиентов, которые заходят редко.
- **Вход через WhatsApp** — нет готовой поддержки в Supabase, сложная интеграция.

## Последствия

- Бесплатно на старте; письма Supabase подходят для разработки, для пилота нужен свой
  SMTP (решение вместе с бюджетом).
- Нужны домен для ссылок приглашений и настройки Apple/Google-входа (этап 2).
