# 0034. Одноразовые приглашения и связи клиента

- **Статус:** Принято; production-домен и native/визуальная приёмка открыты
- **Дата:** 01.10.2026
- **Задачи:** SOM-21, связь с SOM-20/SOM-35

## Решение владельца

Владелец утвердил срок 7 дней, замену старых неиспользованных ссылок при выпуске
новой и принятие любым авторизованным держателем приватно переданной ссылки.
Привязанную карточку другой аккаунт присвоить не может. Один аккаунт клиента
может иметь отдельные карточки у нескольких тренеров. Проверка совпадения
телефона/e-mail с карточкой не требуется и не имитируется.

Production-домен остаётся pending. `EXPO_PUBLIC_INVITATION_BASE_URL` не имеет
значения по умолчанию; без допустимого origin создание ссылки в UI недоступно.
Допустим явно заданный HTTPS origin; HTTP loopback — только development.
Вымышленный домен прототипа не используется. Universal/App Links требуют
отдельной настройки после выбора домена; локальный маршрут `/invite/[token]`
не подтверждает готовность production deep links.

## Серверный контракт

Клиент создаёт 32 криптографически случайных байта, кодирует base64url без padding.
`issue_client_invitation` сохраняет только SHA-256, а не исходный токен. UUID
запроса и токен удерживаются одной командой при повторе после сетевой ошибки.
Приватный receipt содержит хэш и метаданные. Повтор не продлевает срок и не
восстанавливает уже отозванную/истёкшую ссылку; возвращается текущий `active`.

Выпуск/отзыв разрешены только владельцу workspace. Выпуск блокирует workspace,
карточку и затем меняет приглашения; принятие блокирует карточку, затем ссылку.
Замена атомарно отзывает все старые неиспользованные ссылки этой карточки.
`revoke_client_invitation` имеет безопасный повтор по request_id.

`accept_invitation` проверяет auth.uid(), хэш, срок, отзыв и текущую привязку.
Меняется только `client_records.user_id`, сохраняются ID карточки, программа,
записи и история. Повтор принятого приглашения тем же аккаунтом возвращает
успех; другой аккаунт получает общий отказ. Неизвестный/невалидный/истёкший/
отозванный/занятый токен даёт одинаковую ошибку P0002 без личности тренера.
Серверное время проверяется после захвата блокировок.

`list_my_client_connections()` возвращает только ID карточки/workspace и два
отображаемых имени для собственных неархивных карточек. Прямые RLS таблиц не
расширяются; аккаунт клиента не направляется в создание пространства тренера.

## Приложение

Ожидающий токен имеет отдельный ключ в существующем authStorage (SecureStore
native, sessionStorage web). Перед входом намерение сохраняется; после OTP/OAuth
маршрут аккаунта возвращает к приглашению. Принятие требует отдельного нажатия,
вход сам по себе не связывает карточку. При сетевой ошибке намерение сохраняется;
при успехе/окончательном отказе или явном выходе из сценария очищается только
совпадающий токен, чтобы старый запрос не удалил новое приглашение.

До принятия UI не заявляет, что ссылка действительна, и не показывает личность.
После принятия показывает имя из RPC и реальные связи аккаунта. Остальные
клиентские бизнес-экраны всё ещё отдельный этап; демо не выдаётся за эти данные.

Исходный токен выпущенной ссылки остаётся только в памяти экрана. После reload
доступны срок и отзыв, но копирование исходной ссылки невозможно из её хэша;
тренер может выпустить новую. Ссылка копируется через SDK-совместимый
[expo-clipboard](https://docs.expo.dev/versions/v57.0.0/sdk/clipboard/), отправка
открывает системный Share только по нажатию пользователя. Открытие Share не
считается отправкой или принятием. Код приложения не пишет токен в логи, ошибки или аналитику.
Редакция access logs хостинга для URL приглашений проверяется при выборе
production-домена.

## Проверки и границы

Миграции 1800/1900, pgTAP и `invitation_concurrency.py` проверяют права, хэши,
повторы, сохранение истории, несколько тренеров и реальные конкурентные claims /
перевыпуск. Точные результаты app/browser/native — в ROADMAP и review-отчёте.
Production-домен, реальные provider credentials, native deep-link cold/warm
start, два телефона и визуальная приёмка владельца остаются открытыми.
