# 0010. Нативная заставка до загрузки шрифтов

- **Статус:** Принято
- **Дата:** 29.09.2026
- **Кто решил:** исполнитель по handoff ревью каркаса, пункт A4

## Контекст

React-спиннер до загрузки Inter/Montserrat показывает промежуточный интерфейс
с системным шрифтом. Ошибка шрифтов должна оставаться доступной для чтения.

## Решение

Использовать совместимый с SDK 57 `expo-splash-screen`, установленный через
`expo install`. Вызвать `preventAutoHideAsync` на уровне модуля; после загрузки
шрифтов или ошибки — `hideAsync`. Пока результат неизвестен, layout возвращает
`null`. Ошибка выводится как alert внутри SafeAreaView.

## Последствия

Новая библиотека управляет только заставкой; таймеры и искусственная задержка не
добавляются. При ошибке шрифтов заставка скрывается и приложение показывает ошибку.
Expo Go не воспроизводит окончательный вид заставки: его проверка в release-сборке
остаётся частью подготовки к пилоту.

Источник: [Expo SDK 57 SplashScreen](https://docs.expo.dev/versions/v57.0.0/sdk/splash-screen/).
ADR 0007 закрепляет эталон интерфейса; номера 0008–0009 зарезервированы handoff
для отдельных решений из ADR 0006.
