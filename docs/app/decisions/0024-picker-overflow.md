# 0024. Доступная прокрутка picker при нехватке высоты

- **Статус:** Принято
- **Дата:** 01.10.2026
- **Задача:** SOM-50

## Контекст

На iPhone 16e / iOS 26.2 максимальный Dynamic Type
(`accessibility-extra-extra-extra-large`) увеличивает заголовок и подсказку
настолько, что фиксированная верхняя область вытесняет поиск, результаты и Done
за границы шторки. Отключать масштабирование текста нельзя.

## Решение

В режиме `fixedContent` при `fontScale > 1.5` или высоте окна менее 600 единиц
заголовок, подсказка и поиск переходят в общий scroll со списком результатов.
Done остаётся отдельным footer с `flexShrink: 0`. При возвращении обычного
масштаба и высоты header снова фиксируется. Тексты, размеры шрифтов, выбор и
действия не меняются. Обычный эталон 390×844 сохраняет прежнюю структуру.

Это доступный вариант компоновки для ограниченной высоты, а не замена
канонического дизайна. Пороги являются консервативным правилом компоновки;
комбинации максимального текста с клавиатурой и landscape требуют отдельной
проверки. При переходе между режимами поле поиска перемонтируется, поэтому
текущий фокус может сброситься; его controlled value сохраняется у владельца.

## Проверка

На максимальном размере поиск получает фокус и прокручивается в видимую область,
выбранная Планка видна вместе с Done; Done возвращает в редактор без потери
выбора. [До/после](../../../app/review/template-picker/README.md).
Регрессионные тесты проверяют обе ветки и восстановление обычной структуры.
Полная swipe/VoiceOver/TalkBack и визуальная приёмка остаются открытыми.
