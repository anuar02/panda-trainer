# 0005. Маскот в приложении: PNG, затем Rive; без видео

- **Статус:** Предложено
- **Дата:** 29.09.2026
- **Кто решил:** исполнитель

## Контекст

Маскот — красная панда (`design-exploration/MASCOT-DECISION.md`). В `prototype-fresh`
есть PNG-позы, прозрачные видео WebM/WebP для трёх моментов и пробный Rive-риг
(`design-exploration/red-panda-rive-2026-09-29/`, ~9 КБ).

## Решение

1. На старте — статичные PNG-позы через `expo-image` с короткими Reanimated-движениями.
2. Когда риг принят владельцем — `rive-react-native` с состояниями Idle / Wave / Tap и
   дальше новыми позами.
3. Прозрачные видео в нативное приложение не переносим.

## Рассмотренные варианты

- **Видео WebM с альфой** — на iOS VP9 с альфой не воспроизводится; HEVC с альфой
  собирается только на macOS; файлы по 100–250 КБ на позу против ~9 КБ Rive на всё.
- **Lottie** — возможно, но нет встроенной машины состояний; риг уже сделан в Rive.

## Последствия

- Видео остаются в веб-прототипе и как образец движения для аниматора.
- Для этапа 9 нужна приёмка рига на реальных размерах экрана.
