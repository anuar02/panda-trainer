# ADR 0014: явные размеры градиентов и приоритет стилей текста

Статус: Принято. Дата: 29.09.2026.

## Контекст

Первый совместный перенос Today/Home прошёл unit-тесты, но снимки выявили два
расхождения платформ: web-классы NativeWind перекрывали зарегистрированные
StyleSheet-стили Text; Android неверно отрисовывал SVG-фоны с процентными размерами.

## Решение

Text сохраняет объединение классов ADR 0008, но нормализует переданный style в
новый плоский объект. React Native Web получает настоящий inline style с ожидаемым
приоритетом, а native — эквивалентные значения. Проверяются явные fontFamily,
fontSize, lineHeight и color, а не только наличие класса в тесте.

Button также передаёт плоский объект стиля: NativeWind/web терял callback-style
Pressable, включая margin/opacity. Состояния press/hover отслеживаются компонентом,
пользовательские обработчики и style callback сохраняются; disabled остаётся
семантическим запретом, даже если экран явно переопределяет его внешний вид.

SVG-фоны используют измеренную контейнером ширину/высоту и явные stopOpacity
вместо неоднозначного смешения rgba и процентов. Общая реализация остаётся на
уже принятом react-native-svg, без новой зависимости. Радиусы и цвета — из прототипа.

Эллиптический radial задаётся стандартным `r` и матрицей gradientTransform:
rx/ry у radialGradient не поддерживаются браузерным SVG, хотя native их принимает.
Прогресс использует радиальный спад внутри эллипса, а не резко обрезанную заливку.

## Последствия

Дополнительное измерение layout оправдано одинаковым результатом платформ.
Unit-тесты не доказывают совпадение графики: нужны browser computed styles,
снимки Android/iOS и повторная проверка после изменения контейнера.

Montserrat 600 сохраняется для окончания времени в client hero: это явно задано
`prototype-fresh/css/components.css:1365`, хотя первичная спецификация по классам
не включила этот descendant selector. Это уточнение источника, не новый дизайн.
