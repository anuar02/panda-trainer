# 0036. Без обязательных обновлений Linear после каждой задачи

- **Статус:** Принято по прямому решению владельца
- **Дата:** 01.10.2026

Владелец изменил прежнее предпочтение: «there is no need to write down each
time in linear (i changed my mind)». Автоматические записи о каждом пакете
в Linear больше не требуются. Читать scope, зависимости и критерии по-прежнему
можно; технические решения и проверки сохраняются в репозитории.

Коммиты после проверенных задач и продолжение следующей разрешённой задачи
остаются обязательными. Отдельное разрешение на комментарии, project updates
и сообщения людям не предоставлено. Ручная синхронизация Linear возможна по
запросу владельца. Этот ADR уточняет ADR 0020 и последующие workflow-правила.
