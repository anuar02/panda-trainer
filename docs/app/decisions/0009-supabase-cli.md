# 0009. Закреплённый Supabase CLI локально и в CI

- **Статус:** Принято
- **Дата:** 29.09.2026
- **Кто решил:** выделено из ADR 0006, уточнено по handoff A8

## Контекст

Миграции и pgTAP должны выполняться одной версией CLI локально и в CI, без
зависимости database job от React Native и установки всего приложения.

## Решение

Локально CLI 2.118.0 — devDependency приложения; `npm run db -- …` передаёт
`--workdir ..`. В CI `supabase/setup-cli@v1` устанавливает ту же версию;
команды выполняются из корня с `--workdir .`. Лимит job 25 минут, остановка
стека — шаг с `if: always()`. Инструкции и изолированный workdir — в
[`supabase/README.md`](../../../supabase/README.md).

## Последствия

Обновлять версию в package.json, lockfile и workflow вместе.
Локальная разработка требует Docker, облачный проект не нужен.
`db reset` допустим только для одноразовой базы без нужных пользователю данных.
