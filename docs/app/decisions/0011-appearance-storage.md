# 0011. Хранение выбора темы на устройстве

- **Статус:** Принято
- **Дата:** 29.09.2026
- **Кто решил:** исполнитель по ADR 0007 и handoff D6

## Контекст

Прототип сохраняет выбор «Авто / Тёмная / Светлая». Старый каркас выбирал тему
системы и забывал ручную настройку после перезапуска.

## Решение

Expo-совместимый `@react-native-async-storage/async-storage`, установленный через
`expo install`, хранит только значение `auto | dark | light` под ключом
`panda-trainer.appearance`. Это настройка интерфейса, не сессия авторизации.

Роль выводится из группы маршрутов Expo Router. В `auto` тренер получает тёмную
тему, клиент — светлую. `ThemeProvider.workout` всегда включает тёмную тему, не
перезаписывая ручной выбор. Экран журнала ещё не реализован; контракт проверен
unit-тестом и подключён к будущему сегменту `session`.

Чтение старой настройки не заменяет более новый выбор пользователя; записи
выполняются последовательно. Некорректное значение или ошибка чтения оставляют
`auto`. При ошибке записи выбор действует в текущей сессии, но не гарантирован
после перезапуска. Авторизация и SecureStore остаются за ADR 0004.
