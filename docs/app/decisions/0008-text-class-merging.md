# 0008. Объединение классов общего Text

- **Статус:** Принято
- **Дата:** 29.09.2026
- **Кто решил:** выделено без изменения решения из ADR 0006

## Контекст

Базовый Text задаёт цвет и типографику. Переданный компонентом цвет или кегль
должен заменить базовый независимо от порядка сгенерированного CSS.

## Решение

`tailwind-merge` 2.6, совместимый с Tailwind 3, объединяет классы общего Text.
Кастомные размеры шрифта регистрируются в группе `font-size`.

## Последствия

Потребители меняют оформление через className; конфликтующие классы не остаются
в результате. Обновление Tailwind требует отдельной проверки совместимости.
Числа и цвета определяет ADR 0007, а не эта утилита.
