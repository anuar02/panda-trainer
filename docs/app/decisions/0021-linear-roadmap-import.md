# 0021. Полный roadmap в Linear с отдельной приёмкой

- **Статус:** Принято
- **Дата:** 30.09.2026
- **Основание:** прямой запрос владельца заполнить Linear по проекту и оформить документацию

## Контекст

Проект Linear создан по ADR 0020. ROADMAP содержит выполненные demo-срезы и
открытые production-критерии; UI-PARITY и OPEN-QUESTIONS задают отдельные условия
готовности. Простое копирование чекбоксов как Done скрыло бы оставшуюся работу.

## Решение

Этапы 1–11 становятся milestones, решения владельца и исследование — двумя
дополнительными milestones. 69 открытых пунктов этапов 1–10 сгруппированы
в 26 задач с исходными критериями. Приёмка экранов 2–8 имеет отдельные задачи;
native picker, 12 вопросов, исследование и отложенный scope дополняют backlog
до 48 задач. Этап 0 и выполненные demo-пункты описаны как исторический контекст.

59 связей blockedBy отражают production/acceptance prerequisites. Они не запрещают
заранее собирать demo-доказательства или готовить независимые части схемы.
Решения остаются за владельцем; до ответа действуют временные правила.
Все импортированные задачи — Backlog, без назначенных людей, дат и приоритетов.

Обзор — PROJECT-BRIEF, карта IDs и критериев — DELIVERY-PLAN, машинный журнал —
linear-import-2026-09-30.json. Документы Linear имеют те же правила и смысл;
репозиторий остаётся источником технических решений и доказательств.

## Последствия

Агенты находят существующую задачу по карте и обновляют live-записи перед работой.
Разделение крупной задачи сохраняет критерии и связи, а карта обновляется.
Исторические тесты не объявляются свежей валидацией. Импорт не разрешает
комментарии/рассылки, платные услуги, реальные данные, релиз или продуктовые решения.
Публикация этого backlog выполнена по прямому запросу; новые массовые импорты
не следуют из него автоматически.
