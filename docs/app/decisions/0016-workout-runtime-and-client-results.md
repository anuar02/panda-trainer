# 0016. Таймер журнала и клиентские результаты демо

- **Статус:** Принято для демо
- **Дата:** 30.09.2026
- **Кто решил:** исполнитель при переносе поведения канонического прототипа

## Контекст

Журнал уже хранит подтверждённые подходы и черновики (ADR 0015). Следующий срез
связывает редактирование упражнения, отмену записи, отдых и клиентские результаты.
Таймер не должен сбрасываться при переходе между вкладками или писать в storage
каждые полсекунды. Личные заметки тренера не должны попасть клиенту.

## Решение

- Domain-reducer управляет undo, локальными изменениями плана и заметками.
  Исходные упражнения/сохранённые результаты при замене не теряются; новые поля
  декодируются строго, существующий version 1 остаётся читаемым.
- Отдых и выбранное упражнение — отдельный эфемерный context над навигацией,
  с ключом занятие/участник. Только успешная новая запись подхода запускает отдых,
  правка существующей записи его не перезапускает. Undo и завершение очищают отдых.
- Остаток вычисляется от абсолютного deadline, а не числа interval ticks.
  Возврат приложения из фона обновляет часы. Изменения таймера/focus не пишутся
  в AsyncStorage. Полный перезапуск сбрасывает отдых/focus, как у прототипа,
  но не подтверждённые результаты/черновики.
- History/Progress получают данные через чистые селекторы завершённых журналов
  конкретного клиента; клиентская роль демо — c1, не последний участник тренера.
  Только явно shared заметки видимы клиенту. Посещения/списания не выводятся из
  факта завершения журнала. Результаты в будущем не входят в Progress.
- Новых библиотек и серверных операций нет. Голосовой ввод остаётся отключённым;
  альтернативная ручная форма заметки не добавляется без продуктового решения.

## Проверка и границы

Тесты покрывают миграцию старых снимков, replacement chains, undo, изоляцию
участников, приватность, runtime clocks и путь provider → клиент → восстановление.
Native, motion, haptics, техника упражнений и production SQLite/sync остаются
отдельными задачами. Это не основание принять визуальный паритет.
