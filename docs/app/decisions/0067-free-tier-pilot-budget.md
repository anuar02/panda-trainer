# 0067. Бюджет пилота: только бесплатные тарифы

- **Статус:** Принято
- **Дата:** 03.10.2026
- **Кто решил:** владелец продукта

## Контекст

Вопрос №2 (SOM-52). Окружение пилота (SOM-40) требует резервных копий,
проверенных восстановлением, и мониторинга ошибок. Регион и хранение — ADR 0064.

## Решение

Пилот работает только на бесплатных тарифах. Любой платный сервис или переход на
платный тариф — только с отдельного согласия владельца.

| Нужно | Бесплатный вариант | Ограничение, которое учитываем |
| --- | --- | --- |
| База, auth, storage | Supabase Free, EU Central | Нет автоматических ежедневных бэкапов; проект засыпает после 7 дней без активности; свой домен API недоступен |
| Резервные копии | Ночной `pg_dump` через GitHub Actions в приватное хранилище и регулярная проверка восстановления | Бэкап — наша ответственность; секрет подключения хранится только в GitHub Secrets |
| Мониторинг ошибок | Sentry Developer (free) | Лимит событий в месяц |
| Сборки | EAS Free | Ограниченное число сборок в месяц и очередь |
| Push | Expo Push Service | Бесплатен |
| Письма (OTP, приглашения) | Бесплатный тариф SMTP-сервиса (например, Resend) на поддомене владельца | Дневной и месячный лимит писем |
| Страница приглашений | Cloudflare Pages (бесплатно, коммерческое использование разрешено) | — Vercel Hobby не подходит: запрещает коммерческое использование |

## Рассмотренные варианты

- Supabase Pro (~$25/мес) с автоматическими бэкапами — отклонено владельцем на
  время пилота.

## Последствия

SOM-40 выполняется без расходов: вместо встроенных бэкапов Supabase — свой
ночной дамп и проверка восстановления; приложение показывает понятную ошибку,
если проект проснулся не сразу. При росте пилота или исчерпании лимитов решение
пересматривается владельцем.
