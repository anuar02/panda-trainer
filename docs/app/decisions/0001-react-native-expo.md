# 0001. Мобильное приложение на React Native (Expo)

- **Статус:** Принято
- **Дата:** 29.09.2026
- **Кто решил:** владелец продукта

## Контекст

Прототипы — браузерные (`prototype/`, `prototype-fresh/`). Для работы в зале нужно
нативное приложение: клавиатура, шторки, работа без сети, установка на телефон.
Тренеры и особенно их клиенты пользуются и iPhone, и Android.

## Решение

React Native на Expo: managed-проект с development build, Expo Router, TypeScript strict,
сборки через EAS.

## Рассмотренные варианты

- **Swift (только iOS)** — лучшая нативность, но клиенты на Android остаются без приложения,
  вторая платформа удваивает работу.
- **PWA** — быстрее всего из прототипа, но слабее офлайн, клавиатура и установка на iOS,
  нет полноценных push на старых iOS.
- **Flutter** — одна кодовая база, но команда и прототип на TypeScript; Rive и Supabase
  поддерживаются в обоих, преимущества нет.

## Последствия

- Одна кодовая база iOS и Android; веб-версия Expo возможна позже для недельного расписания.
- Браузерный код прототипа не переносится: навигацию, шторки, жесты делаем заново.
- Нужны аккаунты Apple Developer и Google Play для пилота (платно, этап 10).
- Rive доступен через `rive-react-native`.
