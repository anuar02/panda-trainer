# ADR 0012 — SVG-иконки прототипа

Дата: 29.09.2026. Статус: Принято.

## Контекст

ADR 0007 требует геометрию из `prototype-fresh/js/icons.js`; Feather не является
эквивалентом. Иконки должны работать в Expo Go и на трёх платформах.

## Решение

Использовать `react-native-svg`, установленный через `expo install` для SDK 57.
Хранить исходные SVG-фрагменты в `app/src/ui/icons/paths.json`, выводить через
типизированный `Icon` / `SvgXml`. Не переносить старый flameMascot из этого файла:
актуальный маскот — красная панда. Тест сравнивает все геометрии с прототипом.

## Последствия

Нет подмены похожими значками; активная вкладка использует stroke 2.3, остальные
1.8, размер 22. Изменение прототипа выявляется тестом. Нативные снимки и проверка
доступности нужны отдельно: успешный экспорт не означает визуальную приёмку.

Документация: https://docs.expo.dev/versions/v57.0.0/sdk/svg/
