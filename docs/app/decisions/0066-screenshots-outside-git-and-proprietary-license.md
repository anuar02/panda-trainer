# 0066. Снимки экранов вне git и закрытая лицензия

- **Статус:** Принято
- **Дата:** 03.10.2026
- **Кто решил:** владелец продукта

## Контекст

Вопросы №11 (SOM-61) и №12 (SOM-62). Репозиторий весит около 230 МБ, в основном
из-за изображений, и каждый агент клонирует его заново. Лицензия шаблона Expo
была удалена, лицензия продукта не выбрана.

## Решение

1. **Снимки экранов (SOM-61).** Новые PNG-снимки сравнения с прототипом не
   коммитятся в git. В репозитории остаётся текстовый отчёт проверки
   (`app/review/<задача>/README.md`): что сравнивалось, команды и результаты.
   Сами снимки прикладываются к PR вручную или пересоздаются локально скриптом
   сравнения. Существующие PNG остаются как есть.
2. **Лицензия (SOM-62).** Код закрытый: все права защищены. В корне — файл
   `LICENSE` с этим текстом.

## Рассмотренные варианты

- Git LFS — нужна настройка и квота LFS на GitHub.
- Снимки в git, как раньше — репозиторий продолжает расти.
- Открытая лицензия MIT — код можно свободно использовать, в том числе конкурентам.

## Последствия

Агенты не добавляют новые PNG в коммиты; координатор проверяет это при ревью.
Визуальная приёмка опирается на снимки, которые владелец пересоздаёт локально.
