# 0020. Linear для координации работы агентов

- **Статус:** Принято
- **Дата:** 30.09.2026
- **Кто решил:** владелец запросил создание trainerApp в Linear и правила агентов

## Контекст

Владелец предоставил `LINEAR-AGENT-GUIDE.md`. Проект уже хранит план, решения,
handoff и доказательства проверок в репозитории; их нужно связать с Linear.

## Решение

Создать проект trainerApp в существующей команде Something Great / SOM.
Linear хранит исполнимые задачи, статусы и зависимости; репозиторий — технические
решения, план этапов, инструкции и доказательства. Правила проекта закреплены в
[LINEAR-WORKFLOW](../LINEAR-WORKFLOW.md), ссылка на них — в корневом AGENTS.md.
В проекте Linear хранится документ с теми же правилами.

Перед работой агент обновляет live-записи и проверяет дубликаты. Статус Done
требует критериев задачи и применимой приёмки владельцем по ADR 0007.
Комментарии, project updates и сообщения не получают общего разрешения.

## Последствия

Изменения задач синхронизируются с ROADMAP и CHANGELOG в рамках их назначения.
Исторические результаты не объявляются свежими проверками. Массовый перенос
roadmap не входит в настройку проекта. При недоступности Linear агент фиксирует
несинхронизированные изменения и продолжает разрешённую локальную работу.
