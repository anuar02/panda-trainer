# 0060. PNG-маскот и экспериментальный Rive

- Статус: реализовано; визуальная приёмка владельца открыта
- Дата: 03.10.2026
- Задача: SOM-38

Продолжение ADR 0005: локальные утверждённые PNG из prototype-fresh загружаются
через expo-image. Размеры существующих вставок сохраняются. `hidden` полностью
убирает изображение и предназначен для подключения SOM-39.

`EXPO_PUBLIC_MASCOT_RIVE=true` включает rive-react-native только на native для
front (Idle) и wave (Wave), artboard Red Panda. Используется точная копия
red-panda-v5.riv. Флаг по умолчанию выключен. Другие позы и лица остаются PNG:
в экспериментальном риге нет их эквивалентов. Web всегда использует PNG.
Suspense показывает PNG при загрузке модуля; onError возвращает PNG.
Для Rive требуется native development build с библиотекой, не Expo Go.
Metro регистрирует расширение riv. WebM не переносится.

После нового завершения тренировки PNG jump появляется на 2200 мс; геометрия
170×200, bottom 170 взята из `.fx-panda` prototype-fresh/css/fresh.css:772–780.
Старые результаты не запускают празднование. Системное уменьшение движения
подавляет его. Анимации журнала и шторок, настройки SOM-39 не меняются.
Перенос confetti/motion и сравнения на устройствах остаются открытыми;
данный пакет не объявляет полный паритет празднования или приёмку рига.

Документация библиотек: https://docs.expo.dev/versions/latest/sdk/image/
и https://github.com/rive-app/rive-react-native/blob/main/docs/usage-guide.md.
