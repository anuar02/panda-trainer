# ADR 0013: изолированные демо-состояния экранов

Статус: Принято. Дата: 29.09.2026.

## Контекст

UI переносится до принятия auth и схемы. Для сравнения нужны четыре состояния
прототипа; реальные клиентские данные пока запрещены.

## Решение

Экран получает явный `scenario`: normal, empty, loading, offline. Маршрут читает
проверенный query-параметр `scenario`; неизвестное или неоднозначное значение
возвращает normal. Данные — локальные вымышленные fixtures из прототипа.
Действия этой стадии меняют только локальное демо-состояние, без запросов и
обещаний серверного сохранения. Будущий production data layer заменит demo adapter.

Capture передаёт сценарий и ждёт testID его корневого экрана. Поддержка четырёх
состояний включается только для реализованных экранов; остальные отмечаются
как отсутствующие. Скриншот никогда не означает принятие паритета.

## Последствия

Четыре состояния воспроизводимы без скрытых browser-only globals. Query — средство
демо/проверки, не production обработка офлайна или синхронизация. Недоступные
сценарии явно перечисляются; auth и настоящая запись данных остаются отдельной работой.
